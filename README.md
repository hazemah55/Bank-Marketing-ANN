# Bank Marketing Classification Using Artificial Neural Networks

## Project Overview

This project uses Deep Learning to predict customer responses to bank marketing campaigns.

The objective is to develop an Artificial Neural Network (ANN) that performs binary classification using customer and marketing-related data.

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- TensorFlow and Keras
- Artificial Neural Networks (ANN)

## Project Workflow

1. **Data Preprocessing:** Prepared the dataset for model training.
2. **Feature Engineering:** Processed input features and applied feature scaling.
3. **Model Development:** Built an Artificial Neural Network using TensorFlow and Keras.
4. **Model Training:** Applied regularization techniques to support model generalization.
5. **Model Evaluation:** Evaluated classification performance using ROC-AUC.

## Model Performance

| Metric | Reported Result |
|---|---|
| Validation ROC-AUC | 0.9604 |

The reported validation ROC-AUC indicates strong discrimination between the two classes on the validation data.

## Key Learnings

- Building and training Artificial Neural Networks.
- Preparing structured datasets for Deep Learning.
- Applying feature scaling and regularization.
- Evaluating binary classification models using ROC-AUC.

## How to Run

1. Download or clone this repository.
2. Open `Bank_Marketing_ANN_Classification.ipynb` in Google Colab or Jupyter Notebook.
3. Install the required dependencies.
4. Obtain the original dataset and update its file path in the notebook.
5. Run the notebook cells in order.
